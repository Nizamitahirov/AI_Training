QUİZİN “PƏRDƏARXASI” (3 dəq). Bu slayd praktiki hissəni gücləndirir: “Gördüyünüz şey nəzəriyyə deyil - bu otaqda artıq istifadə etdiniz.” Sağdakı telefon animasiyası oyunçunun gördüyü ekranları təkrarlayır: lobbidə avatarlar bir-bir qoşulur və emoji reaksiyalar uçur → 3-2-1 geri sayım → sual, taymer və rəngli cavab plitələri → “Düzdür! +873” → podium və konfetti. Quiz necə quruldu: 1) Claude ilə Kahoot/Wayground tipli platformanın bütün funksiyalarını təsvir edən SPEC.md faylı hazırlandı: ekranlar, sual tipləri, xal düsturu, dizayn, səs, təhlükəsizlik qaydaları. 2) Fayl GitHub-dakı Quizamcham reposuna yükləndi. 3) Claude Code faylı oxudu və tətbiqi mərhələ-mərhələ qurdu. Hər mərhələni bitirəndə dəyişiklikləri main-ə göndərdi. 4) Vercel hər dəfə saytı avtomatik yenilədi. 5) Firebase - mərkəzi “anbar”: kim qoşulub, hansı sual göstərilir, kim nə cavab verib, xallar. Telefonlar bu məlumatı real vaxtda dinləyir - host “Start” sıxanda hamının ekranı eyni anda dəyişir. Admin paneli: suallar Firebase-də saxlanır. Sualı redaktə edib “Yadda saxla” sıxanda dəyişiklik dərhal tətbiqdə görünür - yenidən kod yazmaq və ya deploy etmək lazım deyil. Bu, “məlumat” ilə “kod”un ayrılmasıdır: kod tətbiqin necə işlədiyini, məlumat isə nə göstərdiyini müəyyən edir. Xal sistemi: düzgün cavab 500–1000 xal, nə qədər tez cavab versəniz o qədər çox. Ardıcıl düzgün cavablara seriya bonusu. Fikir: “HR olaraq siz öz komandanız üçün belə alətləri - onboarding quizi, siyasət testi, engagement sorğusu - artıq özünüz qura bilərsiniz.” Qeyd: “7 mərhələ” rəqəmini quiz həqiqətən necə qurulubsa, ona uyğun yeniləyin.
