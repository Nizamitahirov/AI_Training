# Performance Management System
## Məqsəd
Rəhbərlər işçilərə illik hədəf təyin edir və qiymətləndirir.
## Rollar
- HR admin · Rəhbər · İşçi
## Funksiyalar
- Hədəf əlavə et (ad, çəki %, KPI)
- 1–5 bal ilə qiymətləndir, yekun bal
## Texnologiya
- HTML, CSS, JS · Firebase Firestore · Vercel

SPEC.md (4 dəq). Əsas fikir: “Yaxşı spesifikasiya = yaxşı kod. AI-ın yazdığı kodun keyfiyyəti bizim tapşırığımızın keyfiyyətindən asılıdır.” Bu, prompt engineering-in böyük miqyasda tətbiqidir. SPEC (specification) - layihənin texniki tapşırığı. HR dilində: vəzifə təlimatı kimi - tətbiqin “nə iş görməli olduğunu” təsvir edir. Yeddi bölmə: 1) Məqsəd və problem - niyə bu tətbiq lazımdır? 2) İstifadəçi rolları - kim istifadə edir (HR admin, rəhbər, işçi) və hər biri nə edə bilər? 3) Funksiyalar və ekranlar - hansı səhifələr, düymələr, formalar olacaq? 4) Data modeli - hansı məlumatlar saxlanır: məsələn “Hədəf: ad, çəki %, KPI, bal”. Excel cədvəlinin sütunları kimi düşünün. 5) Dizayn - rənglər, şrift, dil, üslub. 6) Texnologiya - nə ilə qurulacaq. Bizdə: HTML (struktur), CSS (görünüş), JavaScript (davranış), Firebase Firestore (buludda verilənlər bazası), Vercel (yayım). 7) Qəbul meyarları - “hazırdır” deməzdən əvvəl yoxlanılacaq siyahı. MARKDOWN: sadə mətn formatı. “#” - başlıq, “##” - alt başlıq, “-” - siyahı. Word kimi proqram tələb etmir, AI üçün idealdır. Sağdakı nümunə əsl SPEC.md-nin başlanğıcıdır. Bonus: təlimin əvvəlindəki quiz üçün yazılmış SPEC.md 25 bölmədən ibarətdir - layihə böyüdükcə spesifikasiya da detallaşır.
