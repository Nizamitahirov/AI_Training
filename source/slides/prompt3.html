VERCEL VƏ İTERASİYA (10 dəq). Vercel addımları: 1) vercel.com → “Sign up” / “Log in” → “Continue with GitHub”. Bu, Vercel-ə repolarınızı görməyə icazə verir. 2) Dashboard-da “Add New…” → “Project”. Siyahıda repo-nuzu tapın → “Import”. Görünmürsə: “Adjust GitHub App Permissions” ilə həmin repoya icazə verin. 3) “Framework Preset” - sadə HTML layihəsi üçün “Other”. Build ayarlarına toxunmayın. “Deploy”. 4) Bir dəqiqəyə yaxın gözləyin - Vercel konfetti göstərəcək və link verəcək. Linki açın, sonra QR kod generatorunda (və ya brauzerin “QR kod yarat” funksiyası ilə) QR yaradıb ekranda göstərin. Auditoriya telefonda açsın - bu, təlimin “vay” anıdır. Avtomatik deploy: bundan sonra Claude Code main-ə hər dəfə dəyişiklik göndərəndə Vercel saytı özü yeniləyir. Heç nəyi təkrar etmək lazım deyil. Təkmilləşdirmə (iterasiya): auditoriyadan soruşun “Nəyi dəyişək?” və onların təklifini Claude Code-a sadə dillə yazın. Hər promptun sonunda “main-ə merge et” deməyi unutmayın. 1–2 dəqiqə sonra telefonda səhifəni yeniləyin - dəyişiklik görünəcək. Xəta olarsa - panikaya ehtiyac yoxdur, bu da dərsin bir hissəsidir: xətanın mətnini (və ya ekran görüntüsünü) Claude Code-a verin və düzəltməsini istəyin. Növbəti slaydda tez-tez rast gəlinən problemlər var.
