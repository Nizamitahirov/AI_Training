PROMPT 2 (15 dəq). Ən təsirli an - agent işləyərkən ekranı auditoriyaya göstərin. GitHub addımları: 1) github.com → sağ yuxarıda “+” → New repository. Ad: kiçik hərflərlə, boşluqsuz (pms-demo). Public seçin (Vercel pulsuz planı ilə rahat işləyir). “Create repository”. 2) Repo səhifəsində “Add file” → “Create new file”. Faylın adı: SPEC.md. Claude-dan kopyaladığınız mətni yapışdırın. Aşağıda “Commit changes” - bu, “yadda saxla” deməkdir. Google Cloud Shell addımları (niyə Cloud Shell? Bu, Google-un brauzerdə açılan pulsuz Linux terminalıdır; Google hesabınızla artıq daxil olmusunuz, ona görə burada işləyən Claude Code Firebase layihənizə tam giriş əldə edir - heç nə quraşdırmağa ehtiyac yoxdur): 3) shell.cloud.google.com ünvanını açın (Firebase layihəsini yaratdığınız Google hesabı ilə). Terminal açılacaq. 4) Claude Code-u quraşdırın: npm i -g @anthropic-ai/claude-code 5) Repo-nu klonlayın və Claude Code-u işə salın: git clone https://github.com/[istifadəçi]/[repo] && cd [repo] && claude. İlk dəfə Claude hesabınızla daxil olmağı istəyəcək - linki açıb təsdiqləyin. Repo-ya push üçün GitHub girişi lazım olacaq: Claude Code “gh auth login” və ya token istəyə bilər - göstərişlərə əməl edin. 6) Promptu yapışdırın, [PROJECT_ID] yerinə Firebase layihənizin ID-sini yazın. Claude Code addımlarını göstərəcək: SPEC.md-ni oxuyur → plan qurur → firebase CLI-ı quraşdırır → Firestore yaradır → web config alır → index.html, style.css, app.js yazır → rules deploy edir → commit → main-ə push. Firebase CLI ilk dəfə giriş istəsə: “firebase login --no-localhost” - linki açıb kodu terminala yapışdırın. Hər təhlükəli əmrdən əvvəl Claude Code icazə soruşur - auditoriyaya göstərin: “agent işləyir, amma son söz bizdədir”. Auditoriyaya izah edin: “Bu, nəzəri hissədə danışdığımız AGENTDİR. Ona məqsəd verdik, o özü plan qurur, alətlərdən (fayl yazmaq, git) istifadə edir və nəticəni yoxlayır.” Promptdakı vacib detallar: • “build aləti olmadan” - Vercel-in heç bir əlavə ayar tələb etməməsi üçün. • “main branch-ə merge et və push et” - Vercel main-dən deploy edir. Claude Code bəzən ayrıca branch-də işləyir; bu cümlə nəticənin dərhal saytda görünməsini təmin edir. • “5 sətirlə izah et” - nəticəni anlamağımız üçün. Gözləmə müddətində (3–8 dəq) auditoriya ilə danışın: “Sizcə, HR-da başqa hansı aləti belə qura bilərik?”
