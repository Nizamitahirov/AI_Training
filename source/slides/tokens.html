TOKEN VƏ KONTEKST (4 dəq). Hər iki panel canlı animasiyadır: solda cümlə tokenlərə bölünür, sağda “masa” dolur və köhnə məlumat düşür. TOKEN. Model hərflərlə və ya bütöv sözlərlə işləmir - mətni “token” adlanan parçalara bölür. Token bəzən bütöv sözdür (“qəbul”), bəzən söz hissəsi (“pros” + “esini”), bəzən bir şəkilçi (“ə”). Animasiyadakı bölgü illüstrativdir - hər model öz “lüğəti” ilə bölür. Animasiyada eyni məna azərbaycanca 8, ingiliscə 5 tokenə bölünür: şəkilçili dillərdə söz daha çox parçaya bölünür, yəni eyni mətn daha çox token tutur. İngilis dilində təxminən 4 simvol ≈ 1 token sayılır. Niyə HR mütəxəssisi bunu bilməlidir? • Qiymət tokenlə hesablanır (xüsusən API ilə işləyəndə) - daha uzun mətn = daha baha. • Limitlər tokenlə ölçülür - həm sual, həm cavab üçün. KONTEKST PƏNCƏRƏSİ. Modelin eyni anda “gözünün qabağında” saxlaya bildiyi mətnin ümumi həcmidir. Analogiya: iş masası. Sağdakı animasiyada masaya təlimat, suallar, cavablar və böyük sənəd düşür. Dolu göstəricisi 100%-i keçəndə ən köhnə məlumat - hətta ilk təlimatınız - masadan düşür. Real modellərin “masası” çox böyükdür, yüzlərlə səhifə sığır, amma prinsip eynidir; həmçinin model çox uzun mətnin ortasındakı detalları zəif “görə” bilər. Praktiki məsləhət: • Yeni mövzu üçün yeni söhbət açın. • Vacib təlimatı söhbətin əvvəlində və lazım gələrsə sonunda təkrarlayın. • Uzun sənəd verəndə ondan nəyi axtardığınızı dəqiq yazın. Vacib: model söhbətlər arasında sizi “xatırlamır” (yaddaş funksiyası ayrıca açılmayıbsa). Hər yeni söhbət - boş masadır.
