LAYİHƏ SEÇİMİ (5 dəq). Səsvermə: hərfləri bir-bir oxuyun, əl qaldırılsın. Hər kartda: layihənin bir cümləlik məqsədi, iki əsas funksiya və 🔥 ilə Firebase-in verdiyi “çox istifadəçili” üstünlük. Hamısı 45 dəqiqəyə qurula bilən MVP həcmindədir. A) PERFORMANCE MANAGEMENT SYSTEM - HR işçilər üçün illik hədəflər (KPI) yaradır, hər hədəfin çəkisi (%) olur (cəmi 100%). Rəhbər hər hədəfə 1-5 bal verir, sistem yekun balı (çəkili orta) və reytinqi (“Gözləntidən yüksək” və s.) avtomatik hesablayır. Firebase sayəsində HR, rəhbər və işçi eyni məlumatı öz ekranlarında görür; idarə panelində şirkət üzrə paylanma canlı yenilənir. Ehtiyat SPEC bunun üçün hazırdır - ona görə vurğulanıb. B) GRADING (vəzifə dərəcələndirmə) - hər vəzifə faktorlar üzrə qiymətləndirilir: bilik və təhsil, məsuliyyət, problem həllinin mürəkkəbliyi, rəhbərlik, ünsiyyət. Ümumi bal dərəcəyə (grade 1-10) çevrilir, hər dərəcənin maaş diapazonu (min-orta-maks) göstərilir. Firebase-də ortaq vəzifə kataloqu saxlanılır - bütün HR komandası eyni bazadan istifadə edir. C) ONBOARDING PORTALI - yeni işçi linki açır və ilk 90 gününü görür: ilk gün checklist-i (noutbuk, giriş, tanışlıq), 30-60-90 günlük məqsədlər, mentorun adı, faydalı keçidlər. İşçi tapşırığı “edildi” işarələyəndə HR öz panelində irəliləyişi (%) canlı görür. D) MİNİ ATS (Applicant Tracking System) - vakansiyalar və namizədlər kanban lövhəsində: Müraciət → Telefon müsahibəsi → Müsahibə → Təklif → İşə qəbul / Rədd. Kartı sürüşdürüb mərhələni dəyişirsən, müsahibə qeydləri və bal əlavə edirsən. Firebase ilə bir neçə HR eyni lövhədə birgə işləyir. E) MƏZUNİYYƏT PLANLAYICISI - hər işçinin illik məzuniyyət hüququ və istifadə etdiyi günlər, qalıq avtomatik hesablanır. İşçi sorğu göndərir, rəhbər təsdiq edir və ya rədd edir. Komanda təqvimində kimin nə vaxt məzuniyyətdə olduğu görünür - üst-üstə düşmələr qırmızı ilə işarələnir. F) eNPS / PULSE SORĞUSU - QR ilə açılan anonim 1 dəqiqəlik sorğu: “0-10 şkala ilə şirkətimizi iş yeri kimi tövsiyə edərdinizmi?” + 2-3 qısa sual. eNPS = promoterlərin faizi (9-10) minus detraktorların faizi (0-6), nəticə -100 ilə +100 arasında olur. Firebase sayəsində nəticə paneli cavablar gəldikcə canlı yenilənir - təlimdə iştirakçılarla elə orada sınaya bilərik! Texniki qeyd: hər layihə HTML, CSS, JavaScript + Firebase (Firestore) ilə qurulur; Claude Code Google Cloud Shell-də işləyərək Firebase-i özü quraşdırır.
