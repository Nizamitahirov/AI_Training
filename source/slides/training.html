Nəzəri hissə

Model necə öyrədilir (training)?

Yeni işçinin inkişaf yolu kimi: təhsil → işə uyğunlaşma → mentorluq

Mərhələ 1

Pre-training

İnternet, kitablar, kod - trilyonlarla token oxunur. Model dili və dünya haqqında ümumi bilik qazanır.

HR analogiyası: universitet təhsili

Mərhələ 2

Fine-tuning

Seçilmiş sual-cavab nümunələri ilə model köməkçi kimi davranmağı, təlimatlara əməl etməyi öyrənir.

HR analogiyası: onboarding

Mərhələ 3

RLHF / Alignment

İnsanlar cavabları qiymətləndirir; model faydalı, dürüst və təhlükəsiz cavab verməyə yönləndirilir.

HR analogiyası: rəy və mentorluq

Vacib: modelin bilikləri bir tarixdə “dondurulur” (knowledge cutoff). Yeni məlumat üçün ona sənəd vermək və ya veb-axtarışı açmaq lazımdır.

MODEL NECƏ ÖYRƏDİLİR (5 dəq). HR analogiyası - yeni işçinin inkişaf yolu - auditoriyaya çox yaxındır. MƏRHƏLƏ 1 - PRE-TRAINING (ilkin öyrədilmə). Model internetdən, kitablardan, elmi məqalələrdən, koddan ibarət nəhəng mətn kolleksiyasını oxuyur. Tapşırıq sadədir: “mətnin növbəti tokenini təxmin et”. Milyardlarla dəfə təxmin edir, səhv edəndə parametrlərini azca düzəldir. Nəticədə dil, faktlar, üslublar, məntiq nümunələri parametrlərə “yazılır”. Bu mərhələ minlərlə xüsusi prosessor (GPU) ilə həftələr-aylar çəkir və çox bahadır. Nəticə: çox bilikli, amma “tərbiyəsiz” model - sualınıza cavab vermək əvəzinə mətni sadəcə davam etdirə bilər. Analogiya: universitet məzunu - çox bilir, amma iş mədəniyyətini bilmir. MƏRHƏLƏ 2 - FINE-TUNING (təlimatlara uyğunlaşdırma). İnsanlar tərəfindən hazırlanmış minlərlə “sual → ideal cavab” nümunəsi ilə model köməkçi kimi davranmağı öyrənir: suala cavab ver, təlimata əməl et, formatı saxla. Analogiya: onboarding - şirkətin qaydaları və iş üslubu. MƏRHƏLƏ 3 - RLHF (Reinforcement Learning from Human Feedback - insan rəyi ilə gücləndirilmiş öyrənmə). Model eyni suala bir neçə cavab yazır, insanlar onları “daha yaxşı / daha pis” deyə sıralayır. Model daha yüksək qiymətləndirilən cavablar yazmağa yönləndirilir: faydalı, dürüst, təhlükəsiz. Bəzi şirkətlər bunu prinsiplər toplusu (“konstitusiya”) ilə də edir. Analogiya: performans rəyi və mentorluq. KNOWLEDGE CUTOFF: pre-training müəyyən tarixə qədərki data ilə bitir. Model bundan sonrakı hadisələri bilmir - yalnız ona veb-axtarış verilsə və ya siz sənəd yükləsəniz öyrənir. Ona görə də “bu il hansı qanun dəyişiklikləri oldu?” kimi suallarda ehtiyatlı olun. Sual: “Şirkətinizin öz datası ilə model öyrətmək lazımdırmı?” Cavab: çox vaxt yox - yaxşı prompt + sənəd vermək (RAG) daha ucuz və sürətlidir.
