PROBLEMLƏRİN HƏLLİ (ehtiyat slayd). Hər şey qaydasında gedirsə, bu slaydı tez keçin və ya göstərməyin. Problem olarsa, burada həll var. • 404 NOT_FOUND - Vercel saytı açır, amma ana səhifəni tapmır. Çox vaxt index.html alt qovluqdadır. Claude Code-a deyin: “index.html, style.css və app.js-i repo kökünə köçür və main-ə merge et.” • Build failed - Vercel kodu “yığmağa” çalışıb uğursuz olub. Sadə HTML layihəsində build lazım deyil: Vercel → Project → Settings → Build & Development Settings → Framework Preset: Other. Və ya Vercel-dəki xəta log-unu kopyalayıb Claude Code-a verin. • Ağ, boş səhifə - adətən JavaScript xətası. Brauzerdə F12 (Mac-da Cmd+Option+I) → Console sekmesi → qırmızı xətanı kopyalayın → Claude Code-a verin. • Dəyişiklik görünmür - Claude Code dəyişikliyi ayrıca branch-də saxlayıb, main-ə göndərməyib. Ona “main-ə merge et və push et” deyin. Həmçinin brauzerdə səhifəni tam yeniləyin (Ctrl+Shift+R). • Vercel repo-nu görmür - Vercel-in GitHub tətbiqinə həmin repoya icazə verilməyib. Import ekranında “Adjust GitHub App Permissions” linki var. • Missing or insufficient permissions - Firestore-un təhlükəsizlik qaydaları (rules) oxumağa/yazmağa icazə vermir. Claude Code-a deyin: “Firestore rules-u SPEC-ə uyğun yoxla, düzəlt və deploy et”. Demo üçün test qaydaları kifayətdir, real datada isə giriş məhdudlaşdırılmalıdır. • Firebase CLI giriş istəyir - Cloud Shell-də “firebase login --no-localhost” əmrini işlədin, linki açın, Google hesabınızla təsdiqləyin və kodu terminala yapışdırın. Əsas mesaj iştirakçılara: “Proqramçı olmadan da xətaları həll edə bilərsiniz - sadəcə xətanı AI-a göstərin və izah etməsini istəyin.”
