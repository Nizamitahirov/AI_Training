AmCham Azərbaycan · NextGen HR Leaders · Süni İntellekt

AI LÜĞƏTİ (5 dəq). Animasiya: yuxarıda 10 termin var, növbə ilə yanır. Aşağıdakı kartın solunda terminin tərifi, sağında isə HR-dan nümunə “yazılır”. Hər termin təxminən 7 saniyə ekranda qalır, tam dövrə təxminən 75 saniyədir. Nümunələri yüksək səslə oxumaq əvəzinə öz sözlərinizlə danışın. • PARAMETR - öyrənmə zamanı tənzimlənən rəqəmlər. Böyük modellərdə yüz milyardlarladır. “Modelin beynindəki əlaqələr” kimi düşünün. • TEMPERATUR - 0-a yaxın: model həmişə ən ehtimal olunan sözü seçir, cavab dəqiq və təkrarlanan olur (məs. siyasət sənədinin xülasəsi). Yüksək: daha yaradıcı (məs. korporativ tədbir üçün şüar ideyaları). • HALÜSİNASİYA - model bilmədiyini “bilmirəm” demək əvəzinə inandırıcı səslənən cavab uydurur. Ən çox rəqəmlərdə, adlarda, istinadlarda, qanun maddələrində olur. • INFERENCE - modelin “işləmə” anı: siz sual verirsiniz, o cavab hesablayır. Training - öyrənmə, inference - istifadə. • MULTIMODAL - model yalnız mətn yox, şəkil, PDF, cədvəl, səs də qəbul edir. • RAG (Retrieval-Augmented Generation) - model cavab verməzdən əvvəl sizin sənədlər bazanızda axtarış edir və cavabı tapdığı hissələrə əsaslandırır. Halüsinasiyanı azaldır. • FINE-TUNING - hazır modeli öz nümunələrinizlə əlavə öyrətmək. Çox vaxt yaxşı prompt + RAG kifayət edir, fine-tuning baha və mürəkkəbdir. • API - proqramların AI-a birbaşa qoşulma yolu. • REASONING - bəzi modellər cavabdan əvvəl “daxili qaralama” edərək addım-addım düşünür. Mürəkkəb analizdə daha dəqiqdir, amma daha yavaş və baha. • MCP (Model Context Protocol) - Anthropic-in təqdim etdiyi açıq standart; AI-ı Google Drive, Slack, verilənlər bazası kimi alətlərə eyni üsulla qoşur. Agentlərin “USB portu” kimi düşünün.
