AGENTIC AI (6 dəq). Bu, praktiki hissənin nəzəri əsasıdır - diqqətlə izah edin. ÇATBOT: siz soruşursunuz → o cavab verir → növbəti addımı yenə siz düşünürsünüz. Hər addımı insan idarə edir. AGENT: siz MƏQSƏD verirsiniz → AI özü: 1) PLAN QURUR - məqsədi kiçik addımlara bölür. 2) ALƏT İŞLƏDİR - veb-axtarış, fayl oxuma/yazma, e-poçt, təqvim, cədvəl, GitHub, verilənlər bazası. “Alət” (tool) - AI-ın xarici dünyada hərəkət etməsinə imkan verən funksiyadır. 3) NƏTİCƏNİ YOXLAYIR - alınıbmı? Xəta var? 4) TƏKRAR EDİR - məqsədə çatana qədər. Bu dövrəyə “agent loop” deyilir. Agentin tərkibi: model (beyin) + alətlər (əllər) + yaddaş/kontekst + təlimat (məqsəd və qaydalar). MCP kimi standartlar AI-ı müxtəlif alətlərə qoşmağı asanlaşdırır. Sağdakı canlı animasiya agentin işini göstərir: yuxarıdakı 4 düymə (Plan, Alət, Yoxla, Təkrar) növbə ilə yanır, aşağıdakı “jurnal”da agentin hər addımı görünür - 50 CV oxunur, problem tapılır (2 CV-də məlumat çatışmır), agent özü təkrar yoxlayır və sonda dayanıb insan təsdiqini gözləyir. Animasiya oynayarkən addımları yüksək səslə şərh edin. HR nümunəsini addımlara bölün: CV-ləri oxumaq (fayl aləti) → meyarlarla qiymətləndirmək (model) → cədvələ yazmaq (cədvəl aləti) → dəvət qaralaması (e-poçt aləti - amma göndərmədən əvvəl insan təsdiqi!). Praktiki hissədə Claude Code məhz agent kimi işləyəcək: ona “SPEC.md-yə uyğun tətbiq qur” deyəcəyik, o özü faylları oxuyacaq, kodu yazacaq, yoxlayacaq və GitHub-a göndərəcək. Risk: agent nə qədər çox alətə çıxış alırsa, səhvin təsiri bir o qədər böyük olur. Qızıl qayda: geri qaytarılmayan addımlardan (e-poçt göndərmək, məlumat silmək, ödəniş) əvvəl insan təsdiqi.
