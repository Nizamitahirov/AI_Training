6 ADDIM (3 dəq). Bu slayd bütün praktiki hissənin “yol xəritəsi”dir. Hər addımı bir cümlə ilə deyin və hansı slaydda ətraflı olacağını qeyd edin: 1) Layihəni seçirik - növbəti slayd, səsvermə. 2) SPEC.md - Claude çatında “Prompt 1” ilə. SPEC = spesifikasiya = texniki tapşırıq. 3) GitHub repo - yeni layihə qovluğu açırıq və SPEC.md-ni oraya qoyuruq. 4) Cloud Shell + Claude Code - shell.cloud.google.com-da terminal açırıq, Claude Code-u quraşdırıb repo-nu klonlayırıq. Cloud Shell Google hesabımızla artıq daxil olub, ona görə Claude Code həm GitHub-a, həm Firebase layihəmizə tam giriş alır. 5) Kod + Firebase - “Prompt 2”. Agent SPEC-i oxuyur, faylları yaradır, Firestore verilənlər bazasını və təhlükəsizlik qaydalarını qurur, hamısını main-ə göndərir. 6) Vercel - repo-nu qoşuruq, 1 dəqiqəyə canlı link. Hesablar təlimdən əvvəl hazır olmalıdır: GitHub, Claude (Claude Code daxil olan plan), Google hesabı (Firebase layihəsi əvvəlcədən yaradılıb), Vercel (GitHub ilə giriş). Hesab yaratmağa təlim vaxtı sərf etməyin.
