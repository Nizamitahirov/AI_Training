ALƏTLƏR (4 dəq). Junior HR-lar üçün bu sözlər qorxulu səslənə bilər - hər birini insan roluna bənzədin. • CLAUDE (çat, claude.ai) - Anthropic-in AI köməkçisi. Söhbət edirik, ideyanı izah edirik, o bizə layihənin texniki tapşırığını (SPEC.md) yazır. Rolu: biznes analitik - tələbləri toplayıb sənədləşdirir. • CLAUDE CODE - Claude-un “agent” rejimi; proqramlaşdırma üçündür. Biz onu GOOGLE CLOUD SHELL-də işə salırıq. Cloud Shell - Google-un brauzerdə açılan pulsuz terminalıdır (shell.cloud.google.com); orada Google hesabımızla artıq daxil olmuşuq, gcloud və digər alətlər hazırdır. Claude Code orada işləyəndə həm GitHub repomuza, həm də Firebase layihəmizə tam giriş əldə edir: SPEC.md-ni oxuyur, faylları (HTML, CSS, JavaScript) yaradır, Firebase-də verilənlər bazasını quraşdırır, təhlükəsizlik qaydalarını yazır və hamısını repoya göndərir (commit/push). Rolu: proqramçı. Bu, nəzəri hissədəki “agentic AI”nın canlı nümunəsidir! • GITHUB - dünyanın ən böyük kod saxlama platforması. REPO (repository) - bir layihənin bütün faylları olan qovluq. Hər dəyişiklik (COMMIT) tarixçədə qalır, istənilən vaxt geri qayıtmaq olar. Analogiya: versiya tarixçəsi olan Google Drive qovluğu. • MARKDOWN (.md) - formatlaşdırılmış sadə mətn. “# Başlıq”, “## Alt başlıq”, “- siyahı”. Word faylından fərqli olaraq, heç bir proqram tələb etmir, AI üçün idealdır. • VERCEL - “hosting” platforması. GitHub repomuzu Vercel-ə qoşuruq, o kodu götürüb internetdə yerləşdirir və bizə link verir (məs. layihe.vercel.app). Ən gözəli: repoda hər dəyişiklik olanda sayt avtomatik yenilənir (DEPLOY). • FIREBASE - Google-un hazır backend xidməti. Tətbiqin “yaddaşı”: məlumatları buludda saxlayır (verilənlər bazası), istifadəçi girişini idarə edir və dəyişiklikləri bütün cihazlara anında çatdırır. Bu günkü quiz məhz Firebase sayəsində real vaxtda işləyir. Bu gün praktiki layihəmiz də Firebase ilə qurulacaq: məlumat buludda saxlanacaq və bir neçə nəfər eyni anda istifadə edə biləcək. Firebase layihəsini əvvəlcədən özünüz yaradın (console.firebase.google.com), qalan qurulumu Claude Code Cloud Shell-dən edəcək. Hamısının pulsuz planı var - təlim üçün kifayətdir. Claude Code üçün isə Claude-un ödənişli planı lazımdır.
