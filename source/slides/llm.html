Large Language Model - Böyük Dil Modeli

LLM-in əsas işi: növbəti söz parçasını (tokeni) təxmin etmək.

1

Large - yüz milyardlarla parametr, trilyonlarla token mətn üzərində öyrədilib.

2

Language - dili, üslubu, faktları və məntiqi nümunələrdən mənimsəyib.

3

Model - bu biliklərin riyazi “sıxılmış” forması.

LLM NƏDİR (5 dəq). Ən vacib slaydlardan biri. Sadə tərif: LLM (Large Language Model - Böyük Dil Modeli) çox böyük həcmdə mətn üzərində öyrədilmiş və bir işi çox yaxşı bacaran sistemdir: verilən mətnin davamını təxmin etmək. Sağdakı animasiyanı göstərin: model “Yaxşı HR menecer” sözlərini görür və növbəti söz üçün hər variantın ehtimalını hesablayır: “işçilərini” 46%, “komandasını” 31%... Ən uyğununu seçir, cümləyə əlavə edir və eyni işi təkrar edir. Bütün uzun cavablar - esse, kod, vakansiya elanı - beləcə, token-token qurulur. Adın üç hissəsi: • Large (böyük) - modelin “parametrləri” var: öyrənmə zamanı tənzimlənən milyardlarla rəqəm. Onları beyindəki neyronlar arası əlaqələrə bənzətmək olar. Model internetin, kitabların, kodun böyük hissəsini “oxuyub”. • Language (dil) - model qrammatikanı, üslubu, faktları və hətta mühakimə nümunələrini mətnlərdən mənimsəyib. • Model - bütün bu biliklərin riyazi formada sıxılmış halı. Model internetə “baxmır” - bildikləri parametrlərindədir (əgər ona ayrıca axtarış aləti verilməyibsə). Niyə vacibdir? Çünki model “bilmir”, “ehtimal edir”. Əgər ən ehtimal olunan davam səhvdirsə, model onu inamla yazacaq. Buna HALÜSİNASİYA deyilir. Məsələn, mövcud olmayan qanun maddəsinə istinad edə bilər. Nəticə: AI-ın verdiyi faktları həmişə yoxlayın. Bonus: “temperatur” ayarı modelin nə qədər “cəsarətli” seçim edəcəyini müəyyən edir. Aşağı temperatur - həmişə ən ehtimal olunan söz (dəqiq, monoton). Yüksək - daha az ehtimal olunan sözlər də seçilir (yaradıcı, amma riskli). İnteraktiv: auditoriyadan cümləni tamamlamağı xahiş edin - onlar da modelin etdiyini edirlər.
