MODEL SEÇİMİ (4 dəq). Hər kartın altındakı narıncı sətir HR-dan konkret nümunədir - meyarı izah edəndə həmin nümunəni deyin. Analogiya: hər tapşırığa ən baha məsləhətçini çağırmırsınız. Sadə iş üçün junior, strateji iş üçün senior. Altı meyar: • MÜRƏKKƏBLİK - çoxaddımlı analiz, strategiya, maaş strukturunun təhlili → ən güclü və ya “reasoning” rejimli model. Sadə mətn işləri → orta model kifayətdir. • SÜRƏT - saniyələrlə cavab lazımdırsa (məs. işçilərə cavab verən çatbot) → kiçik, sürətli model. • XƏRC - API ilə işləyəndə ödəniş token sayına görədir. Kiçik model dəfələrlə ucuz ola bilər; minlərlə CV emal edəndə fərq böyükdür. • KONTEKST - 200 səhifəlik kollektiv müqaviləni təhlil etmək üçün böyük kontekst pəncərəsi lazımdır. • MƏXFİLİK - işçi datası ilə işləyəcəksinizsə: məlumatların təlim üçün istifadə olunmadığı korporativ plan (Team/Enterprise tipli) və ya şirkət daxilində işləyən model. Pulsuz istehlakçı versiyalarına fərdi data yükləməyin. • DİL və FORMAT - Azərbaycan dilində keyfiyyət modeldən modelə fərqlənir; öz tapşırığınızla sınayın. Şəkil, PDF, səs lazımdırsa - multimodal model. Praktiki qayda: tapşırığı 2–3 modeldə eyni prompt ilə sınayın, nəticəni müqayisə edin, sonra standart seçin.
